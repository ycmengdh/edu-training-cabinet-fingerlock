# ESP32 固件换开发电脑说明

本文档用于把 `esp32_firmware` 下的 PlatformIO 固件工程迁移到新电脑。

## 结论

当前固件源码和项目内共享库已经在仓库中，但构建仍依赖新电脑安装 PlatformIO，并由 PlatformIO 下载 ESP32 工具链、Arduino 框架和第三方库。

已在 `platformio.ini` 中固定核心版本，避免新电脑自动拉取不同版本导致构建差异：

- PlatformIO 平台：`espressif32 @ 7.0.1`
- 根节点第三方库：`ArduinoJson @ 6.21.6`、`TFT_eSPI @ 2.5.0`、`lvgl @ 9.5.0`
- 柜子节点第三方库：`Adafruit Fingerprint Sensor Library @ 2.1.4`、`ArduinoJson @ 6.21.6`

## 新电脑联网迁移

1. 安装 Python 3。
2. 安装 PlatformIO Core 或 VS Code PlatformIO 插件。
3. 拷贝或克隆整个仓库，不要只拷贝 `src` 目录。
4. 在根节点工程目录执行：

   ```powershell
   cd esp32_firmware\root_node
   pio run
   ```

5. 在柜子节点工程目录执行：

   ```powershell
   cd ..\cabinet_node
   pio run
   ```

PlatformIO 会按 `platformio.ini` 自动下载工具链和库。

## 新电脑离线迁移

如果新电脑不能联网，需要从旧电脑一并拷贝 PlatformIO 缓存：

1. 拷贝整个仓库。
2. 从旧电脑拷贝以下目录到新电脑同一用户目录：

   ```text
   C:\Users\<旧用户名>\.platformio\packages
   C:\Users\<旧用户名>\.platformio\platforms
   ```

3. 如果不想重新下载项目库，也可以拷贝：

   ```text
   esp32_firmware\root_node\.pio\libdeps
   esp32_firmware\cabinet_node\.pio\libdeps
   ```

4. 新电脑用户名不同也可以，放到新用户的：

   ```text
   C:\Users\<新用户名>\.platformio\
   ```

## 需要保留的项目内文件

迁移时必须保留这些目录和文件：

- `esp32_firmware/root_node`
- `esp32_firmware/cabinet_node`
- `esp32_firmware/common`
- `esp32_firmware/root_node/lib/TFT_eSPI`
- `esp32_firmware/common/partitions_16MB_log.csv`

不要只复制 `.cpp`、`.h` 文件，否则分区表、共享协议库和屏幕库配置会丢失。

## 烧录说明

如果只是烧录已经编译好的固件，不需要完整开发环境；但如果要重新编译、修改代码或生成新固件，就必须按本文档准备 PlatformIO 环境。
