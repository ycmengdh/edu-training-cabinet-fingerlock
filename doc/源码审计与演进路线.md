# 源码审计与演进路线

更新时间：2026-07-18

## 1. 当前结论

项目已经具备可编译的完整骨架，并在本轮完成了管理台可见性、运营功能、模板恢复闭环、固件分区/SD 可靠性与可选 HMAC。

当前可判定为“核心管理能力基本齐全，进入真机联调与压力验收阶段”。仍不能仅凭编译结果判定可正式部署：AS608/继电器/SD/Mesh 压力、掉电恢复与 40 节点稳定性尚未完成。

排除项（用户确认）：
- 首次登录强制改密：不做
- OTA 双分区升级：不做（串口烧录即可）

## 3. 仍未完成 / 风险

### P0：部署前必须完成

1. 硬件在环闭环
   - 真实 AS608：录入、备份、恢复、删除、再识别
   - 继电器默认态/脉冲/重启不误触发
   - 根节点 USB/AP/STA 断线重连与命令幂等
2. Mesh 2/10/40 节点压力与掉电恢复
3. 正式部署前开启 HMAC，并统一配置上位机与各设备密钥；Mesh/AP 默认密码应改为部署期随机凭据
4. 硬件 Flash 容量以实际采购模块为准（板型仍显示 N8 8MB，配置写 16MB）

### P1：可继续增强

1. 权限页按班级批量授权的交互细化
2. 同步失败设备的持久“待同步”队列与自动重试
3. 设备健康告警推送/声音/托盘
4. 配置导入导出与灾难恢复包

### P2：长期

1. 协议版本协商与兼容矩阵
2. 7x24 故障注入脚本与性能基线
3. 二次确认/审批流（远程批量开锁）
