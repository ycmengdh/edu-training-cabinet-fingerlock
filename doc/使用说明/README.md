## 五分钟快速开始

1. 断电状态下插好根节点 SD 卡，接通根节点和所有柜机电源。
2. 等待柜机加入 Mesh，根节点屏幕出现 `SD OK`，并显示柜机在线数量。
3. 用 USB 数据线连接 Windows 电脑与根节点。
4. 启动 `CabinetLock.exe`，选择“组网U盘连接”和根节点 COM 口。
5. 等待启动页依次完成“连接、就绪、备份、同步、完成”。
6. 首次空系统使用 `admin / admin123` 登录，登录后立即修改密码。
7. 在“柜子管理”确认柜机在线；按“角色权限 → 班级 → 老师/学生 → 指纹 → 柜机分配同步”的顺序配置业务。
8. 现场测试指纹开锁，确认日志正常回传。
9. 业务修改后点击主窗口底部“立即同步到 SD”；退出程序时不要跳过退出同步。

> 界面中的“组网U盘”指根节点 USB 串口设备，不是可在资源管理器中打开的普通 U 盘。

## 关键注意事项

- 根节点与柜机串口统一使用 `921600` 波特率。
- 柜机当前固定为 `Mesh + UART0` 同时工作，单柜串口维护不需要长按按键切换模式。
- 柜机可离线执行已经同步到本机的指纹和权限；新建或修改权限必须同步到柜机后才生效。
- SD 卡是集中业务数据源，上位机运行期间使用本机 `business.db` 工作副本。
- 不要在上位机正在同步或根节点正在写入时拔出 SD 卡、USB 线或切断电源。
- 默认密码只用于首次部署或无数据应急。业务库已有账号后，应使用业务库中的有效管理员或老师账号。
