# edu-training-cabinet-fingerlock

学校实训柜指纹智能锁系统。

**硬件**：ESP32-S3 **N16R8**（16MB Flash + 8MB PSRAM）  
**组网**：多柜 **ESP-MESH** 自组网，经根节点汇聚  
**单柜**：保留 **UART0 直连** 上位机，协议与根节点上行相同，可独立控制该柜

更完整的架构说明见 [`doc/系统架构与组网说明.md`](doc/系统架构与组网说明.md)。

## 目录结构

- `FingerprintLockManager/`：Windows 上位机（WPF）
- `esp32_firmware/root_node/`：ESP32 根节点固件，负责 Mesh 汇聚、上行通信、SD 卡和显示屏
- `esp32_firmware/cabinet_node/`：ESP32 柜子节点固件，负责指纹识别、按键和锁控制
- `esp32_firmware/common/`：两个固件工程共用的协议、Mesh 通信和调试代码
- `doc/`：系统功能与方案文档
- `debug/`：硬件联调与通讯压测脚本
- `esp32_firmware/doc/`：ESP32、根节点及硬件资料
- `esp32_firmware/doc/柜子/IO分配.md`：柜子节点真实 GPIO / 74HC595 / UART0 调试口接线表

ESP 固件统一使用 PlatformIO，两个节点是相互独立的工程：

```text
cd esp32_firmware/root_node
pio run

cd ../cabinet_node
pio run
```

根目录不再放置 `root_node`、`cabinet_node` 或 `common` 的副本。

## 系统架构（现行）

```text
上位机 (WPF)
   │
   ├─ 主路径：USB 921600 ──► 根节点 (Mesh Root + SD)
   │                              │ ESP-MESH
   │                         柜机 1 … 柜机 N
   │
   └─ 辅路径：USB-TTL 921600 ──► 单台柜机 UART0（GPIO43/44）
                                 不经 Mesh，协议帧相同
```

| 模式 | 何时用 | 上位机接哪里 | 柜机行为 |
| --- | --- | --- | --- |
| **Mesh（默认）** | 多柜日常部署 | 根节点 USB | 组网找 Root；UART0 协议口也可旁路开着 |
| **单柜 UART（Debug）** | 单台开发 / 检修 | 该柜 UART0（USB-TTL） | 长按任意键约 10s 切入；**不组 Mesh**，仅串口 |

> 单柜控制**不是** AP+TCP，而是与根节点上行同协议的 **UART 串口模式**。

## 系统职责

- **柜子节点**：指纹录入、匹配、权限判断和开锁全部在本地完成。权限缓存在柜内，断网不影响已同步权限的验证；开锁日志不在柜内持久化，仅在 Mesh 可用时即时上报给根节点。
- **根节点**：维护 ESP-MESH；柜机 ↔ 上位机消息经根节点转发。用户、角色权限、设备和指纹模板保存在 **SD 卡**；仅当上位机不在线时，按天暂存开锁日志，最多保留 30 天。
- **上位机**：启动时从根节点 SD 拉取业务表和待同步日志，日志写入本机 `logs.db` 后确认根节点清除；关闭或手动同步时只回写业务数据，不上传日志。上位机离线不参与柜机鉴权。
- **单柜 UART**：`MODE_DEBUG` 下用 UART0（GPIO43/44，921600）直连上位机，便于不经 Mesh 单独控制。

日志流约束：上位机在线时 `柜子 → 根节点透传 → logs.db`；上位机离线时 `柜子 → 根节点 SD 每日暂存`，下次启动拉取成功后清除。管理变更运行期从上位机本地业务库按柜单播到柜机，关闭或手动同步时再将业务库回写根节点 SD。

班级管理可按单台、多选或全部在线柜机分配整班学生，并检测、差异同步指纹和权限；老师主指纹默认面向全部柜机。学生与柜机的分配关系保存在 `users.json` 的 `assigned_device_ids` 中，随 SD 同步往返。

## V2.7 柜机本地交互（窗口化验证 + 副指纹）

- **10 秒操作窗口**：指纹验证成功后进入 10 秒窗口；窗口内按对应锁键开锁，超时或取消则清空本次验证。识别中绿灯慢闪，成功常亮，失败红灯闪 3 次。
- **设备专属副指纹**：单柜本地录入，仅本机生效；全局主指纹与本机副指纹分槽位策略，降低碰撞。
- **三层角色数据隔离**：管理员可见全部；教师仅本班（Service 层 `IDataScopeContext` 强制过滤）；学生仅自己的日志。

## 上位机兜底登录

根节点数据服务或 SD 不可用时，可用内置超级管理员 `admin / admin123` 登录。根节点数据正常时不以该兜底密码为准，仍以 SD 账号为准。

## 协议说明

线上统一为 **外层 A5/5A 帧 + 应用层 B1/0F 二进制信封**；复杂业务 data 仍在信封 payload 内用 JSON。详见 `doc/协议统一说明.md`。

业务数据形态（SD JSON 表 vs 本机 SQLite）见 `doc/业务数据存放形态说明.md`。
